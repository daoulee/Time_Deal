## 수칙 1 — MD 파일 최소화

새 md 파일 생성 금지. 기존 파일 섹션에 추가하는 방식으로.

| 내용 | 기록 위치 |
|------|-----------|
| 수정 이력, 검증 결과 | `검증_보고서.md` |
| 환경/키/빌드 변경 | `기술스택_및_설정.md` |
| 작업 현황 업데이트 | `프로젝트_현황.md` |

꼭 새 파일이 필요한 경우 먼저 사용자에게 확인 후 생성.

## 수칙 3 — 코드 수정 시 주석 필수

코드를 수정했을 때 **수정한 블록의 마지막 줄 바로 아래**에 주석 추가.

### 형식

```
// [Kiro | YYYY-MM-DD] 수정범위: 함수명 또는 블록명 — 수정 내용 한 줄 요약
```

### 언어별 예시

**Dart**
```dart
  Future<void> cancel(String id) async {
    // ... 수정된 코드
  }
  // [Kiro | 2026-08-21] cancel() 전체 — increment_stock RPC 적용으로 레이스컨디션 수정
```

**SQL**
```sql
CREATE POLICY "deals_delete_block" ON deals
  FOR DELETE USING (false);
-- [Kiro | 2026-08-21] RLS deals 섹션 전체 — OR true 제거, DELETE 차단 정책 추가
```

**TypeScript / JavaScript**
```ts
function handleReserve() {
  // ... 수정된 코드
}
// [Kiro | 2026-08-21] handleReserve() — 중복 호출 방지 isSubmitting 플래그 추가
```
